# 主题探索第六轮：适配当前界面

阶段：设计稿，尚未接入正式应用。分支 `codex/theme-design-explorations` 已合并 2026-10-23 的主分支。入口 `style-explorer.html` 是离线单文件画廊；同一批匿名演示账号用于新旧比较。

## 当前产品改变了什么

本轮先以合并后实际运行的演示界面截取 `source-snapshot.json`。现在主看板有一条常驻的「即将刷新」混合队列，以及展开后的 5 小时、7 天、1 个月三条周期队列。桌面设置改成「外观 / 账号 / 监控 / 数据 / 系统」五组，外观是默认组。远程页面另有「当前设备显示」，现在仍把主题当作亮色与暗色二选一；安卓 WebView 的初始片段也只传明暗。旧稿的页脚和设置入口需要跟着这套结构更新。

三套新方向：

| 方向 | 核心意象 | 本轮实际变化 |
| --- | --- | --- |
| 航站时刻 | 倒计时航显 | 卡片做成上下翻牌；额度、周期和底部队列共用琥珀色时刻表语言 |
| 等高线 | 地形图 | 卡片成为地图切片，圆环像等高标尺，队列是地图图例 |
| 赤色坐标 | 印刷信息图 | 六个账号有明确编号，紧密网格与红色标尺把扫读变成坐标定位 |

原来的 16 套皮肤均保留原始 HTML，并另生成 `legacy-*.html` 适配当前组件树。它们仍使用各自的主色、字体、材质和圆环处理，新增了刷新队列、展开把手与五组设置要遵守的通用规则。第一轮四套偏配色的方向适合作为默认亮暗的衍生；第二至第五轮的完整皮肤仍可作为独立主题。此处是视觉适配验证，不能视为已经实现运行时主题系统。

## 主题入口与明暗

桌面保留右上角「设置」入口，外观页由明暗下拉改成可预览的主题库。主题选择是一个决定；“固定主题 / 跟随系统”是另一个决定。固定时主题作者声明亮或暗的有效模式，不能强行反色；跟随系统时用户分别选择亮色主题与暗色主题，没有选择时回退至默认亮色/暗色。桌面浮窗继承桌面已解析的主题，必要时用主题的轻量浮窗变体。

远程页面、安卓应用保留**当前设备**的主题偏好，但不再在看板右上角放亮暗切换。连接前配对页先按手机系统明暗使用默认主题；连接后从「设置 → 当前设备显示」选「跟随电脑」或「本机选择」。若电脑主题未提供可用的移动版，回退至相同明暗的默认主题，并明确提示。手机的默认视图仍是独立设置。

之前安卓的「外部明暗和内部一致」无需作为用户开关。应用每次解析出最终主题后，自动把其 `mode`（light/dark）映射给状态栏、导航栏和启动底色；主题身份与系统栏明暗是两个不同数据。桌面传给 WebView 的明暗提示只能解决首帧闪烁，不能替代主题 ID。若以后支持“跟随电脑主题”，协议应传受支持的主题 ID 与回退模式；不自动加载电脑上的任意 CSS 到手机。

现有设置从 `theme: 'light' | 'dark'` 迁移到提案中的 `themeId`、`appearancePolicy`（fixed/system）、`lightThemeId`、`darkThemeId`。旧值无损映射为默认亮色/默认暗色。默认两款沿用现在的克制视觉，历史配置与同步包依然可读。

## 自定义主题需要包含什么

普通用户从一个内置主题复制，只需填写名称并修改可见参数：亮暗模式、颜色层级、字体、形状、材质强度、额度圆环、状态、队列、抽屉与浮窗。导出为 JSON 草稿即可；高级作者可提交 `.qdtheme` 包，包含必需的 `theme.json`，可选的 `theme.css`、本地字体/纹理/背景和预览图。主题包不能包含脚本、网络加载资源或改变业务数据与操作顺序的布局规则。完整字段示例沿用 [`../round-02/custom-theme.example.json`](../round-02/custom-theme.example.json)，此轮须补足如下主题目标：

| 目标 | 主题作者提供或继承的内容 |
| --- | --- |
| 主题身份 | schemaVersion、id、name、version、author、extends、最低宿主版本、`mode` |
| 主看板 | 窗口/标题栏/卡片/悬浮层/文字/边框/控件/焦点的 token；字体与形状 |
| 数据图形 | 圆环、轨道、中心读数、周期圆点、告警状态，均须保留文字辅助 |
| 当前新增区域 | 混合刷新条、三周期队列、展开把手、可滚动条目与空队列回退 |
| 设置与弹层 | 五组设置页签、主题卡片、输入框、预览草稿、弹层与通知 |
| 多端 | 桌面浮窗主题；远程/安卓移动版主题或安全回退；Android 系统栏依据 `mode` 自动推导 |
| 素材 | 可选背景、纹理、字体、SVG 装饰；所有路径相对主题包，缺失时回退纯色 |

导入后先预览真实数据和四种关键状态（正常、告警、不可用、聚焦），以及当前的刷新队列、设置抽屉和手机窄屏。保存后才应用；取消或导入失败恢复原主题。对比度和缩小视口时的字号应作为导入检查的一部分。主题 CSS 只能覆盖公开插槽及装饰，不能隐藏额度、账号名称、队列或警告信息。

## 本轮文件与局限

`departure.html`、`contour.html`、`coordinates.html` 是新方向；`legacy-*.html` 是旧皮肤的当前界面适配；`appearance-flow.html` 展示桌面外观设置和安卓当前设备设置；`baseline-shots/` 是合并后演示界面截图。`build.mjs` 从本轮快照与旧稿重建全部 HTML。所有账号与读数来自浏览器 demo，设计页内的账户按钮不连接真实数据。安卓原生工程不在此仓库，本轮只依据 `src/remote.jsx`、`src/remote.css` 和主界面的设置代码做体验提案，未修改安卓实现。
