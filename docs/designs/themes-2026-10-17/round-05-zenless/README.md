## 自定义主题需要的内容

承接第二轮的 manifest + 可选样式 + 可选素材：本方向可以没有图片资源，关键是支持组合皮肤插槽。

- `account.header`：亮底铭牌及独立深色前景；不能沿用暗面板的全局文字色。
- `account.body`：暗色设备表面、扫描纹理、双层外边框与底部硬阴影。
- `account.highlight`：外圈、铭牌、读数核心的联动高亮；正式应用需决定它对应悬停还是键盘焦点，不能假装有业务选中状态。
- `quota.core` / `quota.track` / `quota.rings`：核心底色、唱片凹槽、轨道与既有层级色表。显示进度的计算和周期含义不变。
- `control` / `tag`：胶囊/圆形轮廓、边框、反色和焦点轮廓；命中区域不随装饰缩小。
- `background`：点阵、斜纹和大圆环强度，不参与布局，不拦截点击。
- `typography`：品牌、标题、数字、正文分角色指定，缺字体时系统回退。
- 浮窗需单独减弱装饰；正式落地时覆盖抽屉、弹层、图表、告警与不可用状态。

选定后动效提案：铭牌悬停/焦点反色 120ms，主题表面切换 180ms，抽屉进出 180ms；不常驻扫描或闪烁，减少动态效果时直接换状态。本轮尚未实现这些动效。
