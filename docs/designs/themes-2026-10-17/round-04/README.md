## 自定义主题进一步需要支持什么

继承第二轮的 theme.json + 可选 theme.css + 可选 assets 结构，本轮揭示出几个额外需求：

1. **按表面定义前景色**：同一主题可以同时存在亮色铭牌、暗色面板与暗色底栏。不能只用一组全局 ink/背景变量；应支持 titlebar、accountHeader、accountBody、drawer、widget、ticker 等表面自身的文字与边界。
2. **局部材质**：允许把铬金只用于账号头部，不能让文字也变成渐变或依赖反射高光才可见。
3. **轮廓与装饰分离**：撕边、切角、胶带和螺钉作为视觉层，不改业务对象、点击区域或进度计算；裁切只作用于装饰底板，正式实现不能裁掉焦点轮廓。
4. **可选的大尺度背景层**：背景几何不得占布局空间、遮挡数据或截获点击；用户可降低装饰强度，桌面浮窗单独减少纹理和阴影。
5. **素材不是必填**：参数预设即可生成这些风格。只有独有手绘图、金属贴图或授权字体才放入 assets。

明暗模式不足以描述混合主题，应保留主题的 mode 元数据，同时以实际表面检查可读性。跟随系统选择合适主题，不机械反色。
