# 浏览器固定数据预览

运行 `npm run dev` 或 `npm run dev:demo`，打开终端显示的本机地址即可。开发浏览器默认加载 `src/demo/snapshot.json`，可查看账号看板、历史趋势、额度浪费、本机热力图与模型拆分，以及支持渠道的官方用量页。

- `/?theme=light`：浅色主题；默认暗色。
- `/?demo=0`：关闭数据桥，回到原先的浏览器演示账号/不可读取状态。
- 生产环境及 Electron 使用原有接口，不启用演示数据，也不加载快照模块。

## 固定数据与来源

快照于 2026-10-17 从本机 Quota Desk 的现有文件离线提取。账号额度、历史趋势、周期档案与 CLI 用量来自真实记录；账号 ID、名称、身份及自定义渠道名称均替换。历史趋势等距采样，每个账号最多约 1200 个点。CLI 数据按天、渠道与模型聚合，会话只保留重新编号的匿名关联，供跨日去重。

官方逐日用量没有离线存档，因此该页使用与本机数据分开的确定性合成数据，不从本机 CLI 数据推断官方账单；来源同时记录在快照 `provenance` 中。

每次打开都使用同一份数值。日期相对打开当天平移，保留最近一年、最近一个月及倒计时的可用性；不修改全局时钟。页面内筛选、主题、账号编辑和删除只改变当前页面会话，刷新后恢复快照。刷新/扫描按钮重新读取演示数据，不扫描电脑，也不访问厂商。

快照不包含凭据、认证令牌、Cookie、原始账号名称/邮箱、自定义请求配置或私有域名、项目路径或对话。内置厂商的公开网站与 Logo 保留。开发浏览器没有文件和凭据写入能力。真实授权、连接测试、远程访问服务和原生窗口操作不属于本预览的范围。

## 手动替换快照

仅在需要更新整套演示数据时运行：

```powershell
npm run demo:capture
# 指定其他已有 Quota Desk 数据目录：
npm run demo:capture -- --data-dir 'D:\path\to\Quota Desk'
```

捕获脚本仅按白名单读取 `state.json`、`history.json`、`cycles.json` 和只读 SQLite 聚合，不打开 `credentials.json`，不扫描 CLI 原始记录，不发起网络请求，也不写回应用数据目录。日常预览不会自动重新捕获。

验证：`npm run test:demo`。
